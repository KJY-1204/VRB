# Proposal

## Why

VR 볼링 게임의 첫 단계로, 공을 집어 던지고 핀이 쓰러지는 최소 플레이 루프(단계 A)를 만든다. 던지기 손맛이 이 게임의 성패를 가르므로, 정통 점수 규칙(단계 B)과 게임성 추가(단계 C)에 앞서 실기기에서 먼저 검증한다.

## What Changes

- Meta Quest 3S + 컨트롤러 전용 완전 VR 볼링장 환경 (MR/패스스루는 범위 밖)
- 컨트롤러로 공을 집고 릴리스 순간의 손 속도로 던지는 상호작용
- 던지기 보정: 게임 시작 전에 순수 물리 / 약함 / 중간 / 강함 4단계 중 선택. 기본값은 약함. 순수 물리는 릴리스 순간 손 속도를 그대로 전달하고, 약함은 릴리스 직전 약 0.1초의 속도를 평균해 손 떨림만 줄이며, 중간과 강함은 여기에 레인 방향으로 속도를 일부 끌어당기는 보정을 더한다. 단계별 수치는 실기기 튜닝을 위해 한곳의 설정 값으로 둔다
- 핀 10개의 물리 배치와 쓰러짐 판정, 쓰러진 핀 수 계산. 실제 볼링 치수·질량비를 따르고, 공은 연속 충돌 감지, 핀은 낮은 무게중심과 단순 콜라이더, 솔버 반복 횟수 상향, 정지 후 기울기 기준 판정을 쓴다 (세부 수치는 design에서 정한다)
- 쓰러진 핀 수를 보여 주는 간단한 점수 표시와 재시작
- 프레임·투구 단위 데이터 구조는 단계 B 확장을 고려해 미리 잡되, 점수 로직은 입력과 렌더링에서 분리된 순수 로직으로 둔다 (멀티플레이 확장 대비)

범위 밖: 10프레임 정식 점수, 스트라이크/스페어, 스핀·커브, 공 종류, 기록 저장, 멀티플레이, 핸드 트래킹, MR.

## Capabilities

### New Capabilities
- `ball-throwing`: 컨트롤러로 공을 집고 던지는 상호작용, 릴리스 속도 평균화와 던지기 보정 4단계(순수 물리/약함/중간/강함, 기본 약함)
- `pin-physics`: 핀 10개의 배치, 물리 거동, 쓰러짐 판정과 쓰러진 핀 수 계산
- `scoring-display`: 투구 결과를 점수 표시로 보여 주고 게임을 재시작하는 기본 루프와 시작 전 보정 선택 화면

### Modified Capabilities

없음 (기존 spec 없음)

## Impact

- 신규 Unity 스크립트·프리팹: 공, 핀, 레인, 점수 표시, 시작 메뉴 (`Assets/` 하위)
- 씬: `Assets/Scenes/VRB.unity`에 볼링장 환경과 XR Origin 구성
- 의존 패키지: 기존 설치된 XR Interaction Toolkit 3.5.1, OpenXR 1.17.1, Meta OpenXR 2.5.1 사용. 신규 패키지 추가 없음
- 성능: Quest 3S 모바일급 GPU 기준. 핀 10개 물리, 그림자, 라이트맵에 예산 필요
- 빌드: Android 타깃 설정, 실기기 검증 필요
